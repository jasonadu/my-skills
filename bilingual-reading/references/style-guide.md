# 页面样式与交互规范（双语阅读 HTML 版）

来源：SOP「页面样式与细节」。具体实现见 `scripts/book_theme.py`；本文件供排查、
修改样式或验收时对照。**改样式优先改 book_theme.py，一处改全局生效。**

## 1. 整体布局

- 左右两栏：左侧固定目录 `nav#toc`（宽 300px），右侧主内容 `main`
  （`margin-left:300px`，最大宽 900px）。
- 目录 `position:fixed`，随页面滚动保持可见；右上角 ☰ 按钮可折叠/展开。
- 窄屏（≤900px）：目录默认隐藏为抽屉，点 ☰ 滑出，主内容占满全屏；
  窄屏点击目录链接后自动收起抽屉。
- 页面背景 `#faf6f1`，正文字号 18px。

## 2. 配色（CSS 变量）

| 变量 | 值 | 用途 |
|---|---|---|
| `--accent` | `#2563eb` | 强调色（标题条、按钮、链接 hover、中文块左色条） |
| `--zh-bg` | `#f0f6ff` | 中文段落浅蓝底 |
| `--zh-border` | `#2563eb` | 中文块左侧 4px 色条 |
| `--code-bg` | `#0f172a` | 代码块深色底 |
| `--code-ink` | `#e2e8f0` | 代码块浅色字 |
| `--ink` | `#1f2937` | 正文墨色 |

## 3. 字体

- 正文：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 代码：`"SF Mono", Menlo, Consolas, monospace`

## 4. 关键组件样式

| 元素 | 样式 |
|---|---|
| 英文段 `p.en` | 普通段，14px 段距；hover 浅蓝块 + `title="点击显示 / 隐藏中文"` 提示 |
| 中文段 `p.zh` | 浅蓝底 + 左边框 4px `#2563eb` + 圆角右 8px + 内边距 10/16；默认 `display:none`，点击对应英文段切换 `.show` |
| 列表项中文 `li .zh` | 与 `p.zh` 同款浅蓝底+左色条（**历史教训：最初漏了，用户反馈后补上**） |
| 表格 `th/td` | 1px 边框、表头 `#f1f5f9`；中文块附在英文下 |
| 图片 `figure img` | max-width 100%、1px 边框、圆角 8px；figcaption 中英对照 |
| 代码块 `pre` | 深色底 `#0f172a`、横向滚动、13.5px 等宽 |
| 行内代码 | 粉底圆角 `#be185d` |
| 分页按钮 `.pager a` | 三栏等分（上一章/返回目录/下一章），hover 蓝底 |
| 目录链接 | l1/l2 加粗、l3 缩进 20px；hover 浅蓝底 |
| 章节头 `.chapter-head` | 章节标签 accent 色大写、标题 30px、中文副标题灰色 |

## 5. 交互与状态

- 目录折叠：`transform:translateX(-300px)` 过渡 0.25s；宽屏切 `hidden`，窄屏切 `show`。
- 章节内目录点击锚点跳转（`scroll-margin-top:20px` 避免被顶栏遮挡）。
- 中英切换（🌐 悬浮按钮，右下角）：
  - 循环顺序：仅英文 → 仅中文 → 中英对照；
  - 状态存 `localStorage['bilingual-mode']`，**翻页后保持不变**；
  - 仅英文：隐藏全部 `.zh`；仅中文：隐藏 `.en`、显示全部 `.zh`；
    中英对照：`.zh` 默认隐藏，点击英文段展开/收起该段译文。
- 首尾章：上一章/下一章按钮置灰（`disabled`，opacity .4，不可点）。

## 6. 与规范/设计稿的差异（合理裁剪）

- 原始需求若有「弹窗/加载状态/空状态」——本任务为静态阅读页、无交互表单，
  未实现这些状态，属合理裁剪。
- 无外部设计稿时，以用户对首章（样板章）的验收截图为准。
